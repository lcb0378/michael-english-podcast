🔬 Part 4：长难句深度拆解与练习

经典原句：
When it sees a cricket, muscles pull back slowly, like drawing a bow.

保姆级结构拆解：
  • When it sees a cricket 是when 引导的时间状语从句：when（当……的时候）+ 一个完整的小句子，放在主句前面，告诉你主句的动作发生在什么时候——看到蟋蟀的那一刻，肌肉才开始向后拉。英语里 when 从句可以放句首（后面加逗号），也可以放句尾。
  • like drawing a bow 是like + 动名词短语作比较：like（像……一样）+ drawing（动名词），把肌肉向后拉的动作比作拉开一张弓，让你一下子就能想象出那个慢动作。like 后面跟动名词，表示“像做某事一样”。
  • pull back 是短语动词：pull（拉）+ back（向后），两个词合起来才是一个完整的意思——向后拉。英语里很多动词都要和小品词搭伙，才表示得出方向和结果。
  • 整句逻辑链：时间（看到蟋蟀时）→ 动作（肌肉向后拉）→ 画面（像拉弓一样慢）。一句话里藏着时间状语从句、like 比较和短语动词三个机关。

句型练习 · 互动版（练的就是上面拆解的三个知识点；点选项作答，全部选完后点「核对答案」）

A. when 时间状语从句：用括号里的词补全

____ it sees a cricket, muscles pull back slowly.

正确答案：when

Muscles pull back slowly ____ it sees a cricket.

正确答案：when

B. like + 动名词表比较：用括号里的词补全

Muscles pull back slowly, ____ drawing a bow.

正确答案：like

Stretchy tissues work ____ a spring.

正确答案：like

C. pull back 短语动词：用括号里的词补全

Muscles ____ back slowly, like drawing a bow.

正确答案：pull

Then the tongue ____ the meal back.

正确答案：pulls

  2. Stretchy tissues work like a spring, storing power and letting go all at once.
