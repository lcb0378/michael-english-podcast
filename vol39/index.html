🔬 Part 4：长难句深度拆解与练习

经典原句：
If a fold is loose, air leaks through the gap and the plane wobbles, so every fold must be neat and tight.

保姆级结构拆解：
  • If a fold is loose 是If 条件句：If（如果）+ 条件（折痕松了）→ 后面跟结果（空气漏、飞机晃）。英语里 If 条件句专门表示“如果……就……”的假设。
  • air leaks through the gap and the plane wobbles 是and 连接两个分句：and 把两个现象连起来——空气漏出来、飞机摇晃，两个结果同时发生，不用拆成两句话。
  • so every fold must be neat and tight 是so 结果句：so（所以）+ 结论——前面说了松折痕的坏处，所以得出结论：每道折痕都必须整齐、严实。
  • 整句逻辑链：假设条件（If 折痕松）→ 并列结果（漏气 + 摇晃）→ 得出结论（so 折痕要严实）。一句话里藏着条件句、并列分句和结果句三个机关。

句型练习 · 互动版（练的就是上面拆解的三个知识点；点选项作答，全部选完后点「核对答案」）

C. so 结果句：用括号里的词补全

The fold is loose, so the plane ____.

正确答案：wobbles

Workers nap at different times, so the nest never ____.

正确答案：stops
